# 【宝妈必看】妈妈必须知道的母乳喂养知识

> 更新时间：2026-09-16 (UTC+8)

母乳喂养知多少

母乳作为宝宝的第一口食粮，是母爱传递的重要纽带，也是妈妈给孩子珍贵的礼物，对妈妈和宝宝的身心健康影响深远。

世界卫生组织（WHO）和联合国儿童基金会（UNICEF）倡议，**宝宝出生后最初6个月内纯母乳喂****养，且母乳喂养可持续至宝宝2岁及2岁以上。**

那么，母乳喂养到底对妈妈和宝宝有什么好处呢？怎么正确母乳喂养呢？

一起和小编来了解了解吧~

**Q1****母乳喂养对妈妈和宝宝到底有什么好处呢？**

**母乳喂养对母亲的益处**

1. 宝宝的吸吮可以促进妈妈子宫复旧，减少产后出血，**加快产后康复**；

2.** 降低母亲发生卵巢癌、乳腺癌的风险**；

3. **降低糖尿病、高血压等慢性病风险**；

4. 成功的母乳喂养增加妈妈的信心，**降低产后焦虑、抑郁的风险**；

5. 增加亲子互动。

**母乳喂养对孩子的益处**

1. 母乳易消化吸收，有利于宝宝的**肠道健康发育**；

2. 纯母乳喂养能满足婴儿6月龄以内所需要的全部液体、能量和营养素，**应坚持纯母乳喂养6个月**；

3. 母乳的成分和喂养方式，对宝宝的**大脑和智力发育**有正向促进作用；

4. 母乳喂养可**预防宝宝将来肥胖、高血压、糖尿病等基础病的发生**。

**Q2****配方奶是否可以替代母乳喂养？**

答案是，**不可以！**

任何配方奶都不能和母乳相媲美，只能作为母乳喂养失败后的无奈选择。

因此，在无母乳喂养禁忌且母乳充足的情况下，**母乳喂养仍然是宝宝最佳的选择。**

**Q3****什么叫按需喂养？**

所谓按需喂养，即妈妈观察宝宝的哺乳需求信号，及时予以回应。

**切记，不要等到宝宝哭了才喂奶****！**

**Q****4****母乳喂养的妈妈每日饮食**

①每天比孕前增加约80~100g的**鱼、禽、蛋、瘦肉**（每天总量为220g），必要时可部分用大豆及其制品替代；

②每天比孕前增饮200ml的**牛奶**，使总奶量达到每日400 ~ 500ml，并使每日钙总摄入量达1000mg；

③每周吃1~2次**动物肝脏**（总量达85g猪肝，或40g鸡肝）；

④至少每周摄入1次海鱼、海带、紫菜、贝类等**海产品**；

⑤采用**加碘盐**烹调食物。

**Q6****母乳的解冻与加热注意事项**
**母乳解冻**
①**提前一晚从冷冻室取出放冷藏室解冻**；

②紧急情况下，可在37℃温水或温奶器解冻。

**母乳加热**

①冷藏母乳加热，可放入储奶袋/奶瓶放入37℃温水坐浴加热；

②**避免使用沸水/烤箱/微波炉/瓦斯炉加热母乳**，避免烫伤宝宝或导致母乳活性成分失活。

**冷冻母乳的储藏时间**

**①冰箱冷冻＜6个月；**

**②冰箱冷藏＜24小时；**

**③室温存放＜4小时；**

**④已喝过的母乳，室温存放＜1小时。**
